# linuxperf diagrams

`collection.svg` describes collection phases and local outputs. `sharing.svg` describes local export and explicitly configured upload. Both are text-based SVG diagrams of the current implementation, not screenshots or benchmark results. The HTML viewer displays escaped JSON; the diagrams do not imply a dashboard UI.

`collection.svg` показывает фазы сбора, `sharing.svg` — локальный экспорт и явно выбранную публикацию. Это схемы текущей реализации, не скриншоты и не результаты измерений. HTML-представление показывает экранированный JSON.
